Python'da Başka Bir Python Dosyasını veya Kodunu Çalıştırma Yöntemleri

Python içerisinden harici `.py` dosyalarını çalıştırmak veya string olarak verilen Python kodlarını yürütmek için 4 temel yöntem vardır:

1 subprocess Modülü (En Güvenli & Önerilen)

Harici bir python dosyasını ayrı bir süreç (process) olarak çalıştırır. Çıktıları (stdout/stderr) yakalamanıza olanak tanır.

import subprocess

# 1. Dosya çalıştırma ve çıktısını alma
result = subprocess.run(
    ["python", "hedef_dosya.py"], 
    capture_output=True, 
    text=True
)

print("Çıktı:", result.stdout)
print("Hatalar:", result.stderr)

# 2. Arka planda bağımsız başlatma (GUI veya uzun işlemler için)
subprocess.Popen(["python", "gui_app.py"])
Standart kütüphanedir, pip yüklemesi gerektirmez.

2 os.system Yöntemi (Basit Kullanım)

Sistem terminaline doğrudan komut gönderir. Basit işler için uygundur ancak çıktıları değişken olarak yakalamak zordur.

import os

# Terminal komutu gibi python dosyasını çalıştırır
exit_code = os.system("python hedef_dosya.py")

if exit_code == 0:
    print("Başarıyla çalıştırıldı!")
else:
    print("Hata kodu:", exit_code)
Eski bir yöntemdir, karmaşık çıktılar için `subprocess` tercih edilmelidir.

3 exec() Fonksiyonu (Dinamik Kodu Çalıştırma)

Metin (String) formatındaki Python kodlarını dinamik olarak mevcut çalışma alanında çalıştırır.

# Metin halindeki python kodunu çalıştırma
python_kodu = """
def selamla(isim):
    return f'Merhaba {isim}'

print(selamla('Ahmet'))
"""

exec(python_kodu)

# Dosyadan okuyup içeriğini exec ile çalıştırmak:
with open("script.py", "r", encoding="utf-8") as f:
    exec(f.read())
Güvensiz kaynaklardan gelen string'lerde kullanırken dikkat edilmelidir.

4 importlib Modülü (Modül Olarak İçe Aktarma)

Başka bir Python dosyasını dinamik olarak modül gibi içeri aktarır ve içindeki fonksiyonları çağırır.

import importlib

# 'hesapla.py' dosyasını dinamik olarak import eder
modul = importlib.import_module("hesapla")

# Modül içindeki fonksiyonu çağırma
sonuc = modul.topla(5, 10)
print(sonuc)

# Modülü yeniden yüklemek istenirse:
importlib.reload(modul)
Modüler mimariler ve eklenti sistemleri için idealdir.

Python Kodunun İçinden PIP Paketlerini Otomatik Yükleme

Projeniz çalıştırıldığında eksik kütüphaneleri otomatik kontrol edip yüklemesini sağlayan kod yapısı:

import sys
import subprocess

def package_install(package_name):
    """Eksik paketi programmatik olarak pip ile kurar"""
    print(f"[{package_name}] kütüphanesi yükleniyor...")
    subprocess.check_call([sys.executable, "-m", "pip", "install", package_name])
    print(f"[{package_name}] başarıyla yüklendi!")

# Örnek Kullanım: Requests kütüphanesini kontrol et ve yükle
try:
    import requests
    print("Requests kütüphanesi zaten yüklü.")
except ImportError:
    print("Requests kütüphanesi bulunamadı, otomatik yükleniyor...")
    package_install("requests")
    import requests

# Artık kullanılabilir:
# response = requests.get("https://api.github.com")

Python GUI (Arayüz) Kütüphaneleri ve exe Dönüştürme

Masaüstü uygulaması geliştirmek için kullanabileceğiniz ana framework'ler ve tek tıkla `.exe` yapma yöntemleri.

Tkinter / CustomTkinter Dahili / Kolay

Python ile birlikte dahili gelen standart GUI kütüphanesidir. Modern görünüm için CustomTkinter tercih edilebilir.

# Pip ile modern Tkinter yüklemek için:
# pip install customtkinter

import tkinter as tk

root = tk.Tk()
root.title("Python GUI")
root.geometry("300x150")

label = tk.Label(root, text="Merhaba Tkinter!")
label.pack(pady=20)

root.mainloop()
PyQt6 / PySide6 Gelişmiş / Profesyonel

C++ Qt framework'ünün Python bağlamıdır. Karmaşık ve profesyonel masaüstü yazılımları için 1 numaralı tercihtir.

# Yükleme: pip install PyQt6

from PyQt6.QtWidgets import QApplication, QLabel, QWidget, QVBoxLayout

app = QApplication([])
window = QWidget()
window.setWindowTitle('PyQt6 Örneği')

layout = QVBoxLayout()
layout.addWidget(QLabel('Merhaba PyQt6!'))
window.setLayout(layout)

window.show()
app.exec()

Python Dosyasını Tek Tıkla Masaüstü (.EXE) Uygulamasına Dönüştürme

Geliştirdiğiniz `.py` scriptlerini ve GUI uygulamalarını kullanıcının bilgisayarında Python yüklü olmasa bile çalışabilen tek bir `.exe` dosyası haline getirebilirsiniz.

1. PyInstaller Yükleyin pip install pyinstaller
2. EXE Oluşturun pyinstaller --onefile --noconsole main.py
3. Dosyayı Alın Oluşan `.exe` dosyası projenizdeki dist/ klasörü içinde yer alacaktır.
